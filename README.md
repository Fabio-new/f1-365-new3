# F1 365 V12 — versione piatta per GitHub da iPhone

Questa versione NON usa cartelle obbligatorie e NON usa Serverless Functions.
Tutti i file del sito sono nella root del repository.

## Upload
Carica tutti i file estratti direttamente nel repository GitHub.

Root attesa:
- index.html
- news.html
- calendar.html
- results.html
- standings.html
- drivers.html
- teams.html
- live.html
- style.css
- site.js
- hero.jpg
- robots.txt
- sitemap.xml
- 404.html

Non serve vercel.json.

## Dati
Calendario, risultati, classifiche, piloti e team usano il servizio pubblico Jolpica-F1 dal browser.
Le News rimandano alle fonti ufficiali Formula1.com e FIA.
